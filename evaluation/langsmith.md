## What We Measured

### Round 1 Evaluation (Manual, 5 cases)

Five synthetic leases tested against five pass/fail criteria:

| Criterion | Pass threshold | Result |
|---|---|---|
| C1 Extraction completeness | ≥90% of present fields extracted | 5/5 PASS |
| C2 Extraction accuracy | ≥90% of values match ground truth | 5/5 PASS |
| C3 No hallucination | Zero invented values for absent fields | 5/5 PASS |
| C4 Flagging relevance | ≥75% precision on flagged clauses | 5/5 PASS |
| C5 Output usability | Lawyer can use without source document | 5/5 PASS |

**Limitation acknowledged:** 5 synthetic cases is sufficient to validate the approach
but not to establish a statistically reliable accuracy figure. Real lease testing
required.

### Experiment: Accuracy vs Ground Truth

**Evaluator type:** Rule-based (exact match on key fields)

**Fields evaluated:**
- tenant_name: exact match after normalisation
- landlord_name: exact match after normalisation
- lease_commencement_date: exact ISO date match
- lease_expiry_date: exact ISO date match
- rent_amount: numeric value within 5% tolerance
- break_option_date: exact date match (null = null)
- expected_risk_level: high/medium/low classification match

**Evaluator logic (pseudo-code):**
```python
def evaluate_extraction(result, ground_truth):
    score = 0
    total = 0
    for field in KEY_FIELDS:
        if ground_truth[field] is not None:
            total += 1
            if normalize(result[field]) == normalize(ground_truth[field]):
                score += 1
    return score / total if total > 0 else 0
```

## What Failed

**Issue 1: Portuguese terminology extraction**
The extraction prompt initially used English field labels only. The synthetic leases
use Portuguese labels (SENHORIO, ARRENDATÁRIO). Fields returned "Not found" until
Portuguese terminology mappings were added to the system prompt in prompts.py.

**Fix applied:** Added Portuguese-to-English field mapping in EXTRACTION_SYSTEM.

**Issue 2: Claude agreement score returning 0%**
Claude Haiku was wrapping its JSON response in markdown fences (```json ... ```).
The original `safe_parse_json` function did not strip these, returning an empty dict
and defaulting agreement_score to 0%.

**Fix applied:** Updated `_parse_json_robust` in validator.py with three-strategy
parsing: direct parse, strip markdown fences with regex, find first {…} block.

**Issue 3: lease_text not substituted in extraction prompt**
The `build_extraction_prompt` function used `.format()` which failed on curly braces
in the legal context strings. The `{lease_text}` placeholder was not being replaced.

**Fix applied:** Changed to `.format(pt_fields=..., few_shot=...).replace("{lease_text}", lease_text)`.

## What a Pilot Would Watch

**1. Accuracy on real Portuguese leases:**
The 200-lease corpus is synthetic. Real leases will have different clause wording,
formatting, and edge cases. The pilot must measure accuracy on at least 20 real
leases before drawing conclusions about production accuracy.

**2. Claude agreement score calibration:**
The current Claude validation uses a confidence-based approach. In the pilot, we
need to verify whether high Claude agreement (≥85%) actually correlates with correct
extraction, and whether low agreement (≤60%) reliably flags genuine errors.

**3. Reasoning model accuracy on complex clauses:**
o1, o3, and o3-mini are available but have not been benchmarked against gpt-4o-2024-11-20
on real leases. The pilot should run 10 leases through both gpt-4o and o3-mini and
compare flagging quality, especially on break conditions and assignment restrictions.

**4. Prompt regression:**
LangSmith dataset should be used as a regression suite. Any prompt change must be
run against the full 200-lease corpus before deployment. Minimum acceptable: no
regression on C1-C5 criteria from Round 1.

**5. Feedback loop effectiveness:**
After 20+ lawyer corrections are stored in Supabase, measure whether few-shot
injection improves accuracy on the specific fields that were corrected. This is
the key mechanism for the system learning from real use.
